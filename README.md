# Meu Portfólio Pessoal

**Aluna:** Valéria Lopes do Couto

## Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar minha trajetória como estudante do curso Técnico em Análise e Desenvolvimento de Sistemas.

O site reúne informações sobre meu perfil, habilidades, projetos acadêmicos e formas de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git e GitHub

## Estrutura do portfólio

- Início: apresentação pessoal.
- Sobre mim: informações sobre minha trajetória e interesses.
- Habilidades: tecnologias e conhecimentos.
- Projetos: apresentação dos trabalhos acadêmicos.
- Contato: links para GitHub e LinkedIn.

## Funcionalidades

- Menu de navegação entre as seções.
- Layout responsivo com Bootstrap.
- Cartões para apresentação dos projetos.
- Links para os repositórios do GitHub.
- Efeitos visuais ao passar o mouse sobre os cartões.

## Recurso adicional

Foi implementado um efeito de transição nos cartões, que se movimentam levemente para cima quando o visitante passa o mouse sobre eles, proporcionando uma experiência visual mais interativa.

## Objetivo

Aplicar os conhecimentos adquiridos durante o curso Técnico em Análise e Desenvolvimento de Sistemas e desenvolver minha presença profissional na área de tecnologia.
